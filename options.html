Agentic AI Assistant Options

Important: Make sure to select "write" access when creating your API token to use the Inference API.

How to get your Hugging Face API key:

  1. Go to Hugging Face Tokens
  2. Sign in or create an account
  3. Click "New token"
  4. Give it a name (e.g., "Chrome Extension")
  5. Select "write" access (required for Inference API)
  6. Copy the generated token
